# CODEX AI MARKET — Binany Trading Dashboard (Paper-Trading MVP)

A mobile-first Express/TypeScript dashboard prototype for technical-indicator signals and simulated paper trades.

> **Demo only. Not a live trading bot.** This project does not connect to Binany, authenticate to a broker, or place real orders. It does not use a trained AI model; signals are generated by a simple indicator/confluence rules engine. Do not use its signals or simulated results to make real-money decisions.

## What it currently does

- Serves a single-page dashboard from `public/index.html`.
- Requests public Binance Spot candles for supported symbols such as `BTCUSDT`, `ETHUSDT`, and `BNBUSDT`.
- Calculates EMA 9/21, RSI 14, Bollinger Bands, candle direction, and recent range levels.
- Produces a heuristic `CALL`, `PUT`, or `WAIT` result with a rule-based score labelled as confidence. This percentage is **not** a statistically validated win probability.
- Accepts paper-trade requests with server-side maximum-stake, daily trade-count, and cooldown checks.
- Includes a browser-side demo wallet and paper-trade history.

## Critical data and risk limitations

- OTC, index, synthetic, slash-separated, and other unsupported symbols use **generated simulated candles**.
- When a Binance request fails or the pair is unavailable, the backend also falls back to generated simulated candles.
- The browser animates the latest price locally between data loads. These changes are not exchange ticks.
- Paper-trade settlement and the wallet/history run in the browser. The backend does not receive settled P/L, so the configured daily-loss limit is **not currently an effective server-side loss stop**.
- State is held in memory and resets when the server restarts. This is a prototype, not a persistent trading ledger.

Treat every OTC/synthetic/fallback result as mock data. Connect an authorized market-data feed and implement backend settlement, persistence, and tests before relying on any risk controls.

## Requirements

- Node.js 22 or newer.
- npm.
- Internet access for public Binance market-data requests and initial dependency installation.

## Run locally

```bash
npm install
cp .env.example .env
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The server binds to `0.0.0.0` by default, so a device on the same local network can access it using the computer's LAN IP. Avoid exposing this unauthenticated prototype directly to the public internet.

### Android / Termux

```bash
pkg update -y
pkg install nodejs-lts -y
# Extract the ZIP, then cd into the project directory
npm install
cp .env.example .env
npm run dev
```

Open `http://127.0.0.1:3000` in the same device's browser.

## Configuration

Copy `.env.example` to `.env` and change values as needed:

| Variable | Default | Purpose |
|---|---:|---|
| `APP_HOST` | `0.0.0.0` | Server bind address |
| `APP_PORT` | `3000` | Server port (`PORT` takes precedence when supplied by a host) |
| `MAX_STAKE_USD` | `1.0` | Maximum accepted paper-trade stake |
| `DAILY_LOSS_LIMIT_USD` | `5.0` | Planned daily-loss threshold; not yet enforced correctly because settlement P/L is browser-side |
| `MAX_TRADES_PER_DAY` | `20` | Server-side paper-trade count cap per UTC day |
| `COOLDOWN_SECONDS` | `60` | Minimum interval between accepted paper-trade requests |
| `PAPER_MODE` | `true` | Keeps the paper-trade endpoint in demo mode |

Never commit `.env`, passwords, API keys, access tokens, or session cookies. The example file contains safe defaults only.

## API endpoints

### `GET /health`

Returns service status and in-memory paper-mode counters.

### `GET /api/candles?symbol=BTCUSDT&timeframe=1m`

Requests Binance Spot candles for supported symbols. The current fallback behavior can return simulated data for unsupported symbols or failed requests; an HTTP-success response does **not** guarantee that the candles are live.

### `POST /api/signal`

Example request:

```json
{
  "symbol": "BTCUSDT",
  "timeframe": "1m",
  "expiry_seconds": 60,
  "market": "REAL",
  "strategies": ["ema_rsi", "price_action", "bollinger", "support_resistance"]
}
```

The endpoint returns a rule-based direction, score, indicator values, and reasons. It is not financial advice and confidence is not a validated win-rate estimate.

### `POST /api/paper-trade`

Accepts a paper-trade request after its current checks. It never submits an order to Binany or another broker.
